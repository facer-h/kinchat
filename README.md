# 即时通信网络聊天室（KinChat）

基于 **C++ / Boost.Asio** 实现的轻量级实时即时通信聊天室系统。采用**免注册昵称进入**模式，支持**在线私聊、群聊、会话级联系人管理、心跳在线状态感知**等核心能力，**纯内存存储、零数据库依赖**，开箱即用。

> **项目定位**：网络编程 / 即时通信原理教学演示、局域网轻量沟通、小型兴趣社区二次开发。

---

## 功能特性

### 核心功能（P0）

- 免注册昵称进入 / 离开聊天室（唯一性校验）
- 心跳保活与在线 / 已离开状态判定
- 连接到超时自动下线
- 一对一私聊（仅限在线用户）
- 群聊 / 公共聊天室
- 在线用户列表、会话级联系人列表（添加 / 删除、实时在线状态）
- 并发在线支持（≥ 100）、昵称与消息合法性校验

### 非核心功能（P1）

- 会话内修改昵称、断线后自动重新加入
- 会话历史记录（内存缓存）
- 在线用户 / 联系人搜索
- 进入 / 离开聊天室广播、系统公告、未读消息提醒

### 拓展功能（P2）

- 消息撤回、表情包 / Emoji、图片 / 文件传输
- 联系人分组、自定义建群与群管理
- 传输加密（TLS）、敏感词过滤 / 禁言、本地文件持久化

> 完整的功能划分、优先级与验收标准见 [`docs` 分支](https://github.com/facer-h/kinchat/tree/docs) 中的需求文档（PRD）。

## 架构概览

系统由 `ChatService`（服务调度层）与 `Session`（连接会话层）两层构成：单个 `io_context` 统一调度异步 I/O，`acceptor` 异步接受新连接，每个对端封装为一个 `Session`，通过异步读 + 写队列实现全双工通信，消息经 `handleMessage` 路由分发。

```
                         ┌──────────────────────────────────┐
                         │           ChatService            │
                         │  io_context / acceptor / socket  │
                         │  clients_        在线用户集合     │
                         │  Conservations   群聊集合         │
                         │  doAccept()      异步接受连接     │
                         │  handleMessage() 消息路由         │
                         │  closeSession()  会话清理         │
                         └──────────────┬───────────────────┘
                                        │ 新连接
                         ┌──────────────▼───────────────────┐
                         │             Session             │
                         │  socket_ / buffer_ / writeQueue_ │
                         │  doRead()      异步读            │
                         │  doWrite()     异步写（写队列）    │
                         │  BroadCast()   群聊广播           │
                         └──────────────┬───────────────────┘
                                        │
                      ┌─────────────────┼──────────────────┐
                      │                 │                  │
                  客户端 A          客户端 B           客户端 C
```

详细设计见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。
